# 交互骨架（双旋钮 + 可换屏 HUD）

记录日期：2026-10-08。真屏 ST7789P3 240×284 横置逻辑 **284×240**（`rot=3`，gate gap 36，圆角 `TFT_SAFE=14`）。

**页面架构 / 分期 / 设备·手机分工 → [UI_OS.md](UI_OS.md)。**  
本文件管旋钮语义与五模式；开机 splash → Home 仪表盘 → 长按进入模式页。

硬件约束：15 键始终是音符；左手 ENC2、右手 ENC1。不做多层菜单；板上是专用乐器 OS，不是安卓式文件管理器。

## 旋钮语义（固定）

| 控件 | 动作 | 含义（任何模式都不变） |
|------|------|------------------------|
| ENC2 左 | 转 | 音量 0–100，每格 1；开机默认 20。100 = 满幅（原先按 /255 只到约四成） |
| ENC2 左 | 短按 | 静音 / 恢复 |
| ENC2 左 | 按住再转 | 移调 −12…+12 半音（默认 C）；每格预听 K1 |
| ENC1 右 | 转 | 当前模式列表，**只改选中，不加载**。按脉冲间隔变速：Δt>50ms×1，20–50ms×5，≤20ms×20（无松手滑行） |
| ENC1 右 | 短按 | 确认：加载 / 播暂停 / 跟练开停 / 录制开停 |
| ENC1 右 | 长按 ≥700ms | **只切模式**（按住期间转过则不算长按） |
| ENC1 右 | 按住再转 | 播放倍速 0.5×–2.0×，每格 0.1；谱和音乐共用，默认 1.0×。屏右上角 `x1.0` |

15 键不参与菜单。MUSIC / FOLLOW / RECORD 里按键仍然出声。

## 五个模式

长按循环：`play → music → score → follow → record → play`

切模式时停掉正在播的 BGM 和自动谱。

| 模式 | 列表 | 短按 | 屏主区 |
|------|------|------|--------|
| **play** | 音色 bank | 加载 bank | 上/当前/下 bank |
| **music** | `/sdcard/music` 音频索引 | 播选中；播完自动下一首 | 曲名 + 进度 |
| **score** | `/sdcard/puzi` 谱索引 | 播/暂停/继续；播完自动下一首；音符同步 BLE HID/MIDI | 谱名 + 进度 |
| **follow** | 同 score | 开/停跟练（等键，不自动放音） | 15 列等待瀑布流 + 判定线 + 进度 |
| **record** | 已录列表 | 开始/停止；停止后写入 `/sdcard/puzi` | 录制时长 + 音符数 |

大库：PSRAM 路径索引上限 **2048**（原 768；非 FAT 限制）。屏上 5 行窗口 + `idx/total`。选中≠正在播时提示「点确认」。

## 屏布局（284×240 焦点中心）

内容落在安全矩形内（约 `(14,14)–(270,226)`）；背景可满屏。

```text
┌─ header ──────────────────────────────────────┐
│ 曲谱（模式强调色）     72% · 音量20           │
│                        C · x1.0               │
├─ focus ───────────────────────────────────────┤
│   上一项（淡）                                │
│ ┌───────────────────────────────────────────┐ │
│ │ ▶ 当前选中                     n/total    │ │
│ └───────────────────────────────────────────┘ │
│   下一项（淡）                                │
│   播放中 / REC / 跟练状态（一行）             │
├─ footer ──────────────────────────────────────┤
│ ████████░░░░  1:23/3:40   （仅有进度时）      │
│ 转=浏览  短按=确认 / 长按切模式…              │
└───────────────────────────────────────────────┘
```

- follow 进行中：焦点框改显示 `第 n/总` + 对/错；谱名落到副行。
- record 录音中：焦点框显示 `REC mm:ss` + 音符数。
- **不画** 15 键电平条（与 RGB 灯重复）；板上跟练靠单键灯。见 [APP_FEATURE.md](APP_FEATURE.md)。
- 开机：`splash` → **HOME 仪表盘**（左上 `HOME`）。音色索引扫完前忽略右旋，避免误进弹奏页。
- Home：**短按或旋转** → Library；库内短按进模式。
- Home 后台条：双击回 Home 后若音乐/谱/跟练/录音仍在跑，主区显示「后台 …」状态条（手机 now-playing 式），不自动停播。
- 回 Home：模式/库页 **长按**，或 **双击** 右旋钮。
- 模式页短按确认会 **延迟 ~380ms** 再执行，避免双击回 Home 时第一下被当成暂停/开停。
- 左旋：转=音量，按住转=移调，短按=静音，长按=Quick Panel。
- 串口：`tft home` / `tft lib` / `tft qp` / `tft theme sky|night|+` / `tft bg <path>|clear|reload`。架构见 [UI_OS.md](UI_OS.md)。
- 皮肤：默认 **sky** + 出厂底图 `bg_sky.raw`（晨岛）；**night** + `bg_night.raw`。用户图放 `/sdcard/ui/`。QP 开时转 ENC1 切换。

## 音频格式（music）

| 格式 | 状态 |
|------|------|
| WAV / MP3 / FLAC / AAC | 板上直接播放（重采样到 22050 mixer） |

## 跟练 / 录制

共用现有谱：`ScoreNote { t_ms, key 1..15 }`，文件在 `/sdcard/puzi`。15 键照常出声。灯只提示「该按哪一颗」，不画 15 路电平。

### 跟练 follow

短按：选中的谱还没开 → 打开并进入等待；已在跟 → 停止。

只走「等正确键」，不卡节奏（节奏窗以后再加）：

1. 停掉 BGM / 自动放谱。
2. 指针停在当前音符（同一 `t` 的和弦一起等）。
3. RGB：该按的键常亮，其余灭。屏：**15 列等待瀑布流**（3×5：键 1–5 / 6–10 / 11–15，组间 5|6、10|11 为实线）——当前和弦小方块停在判定线，后续音按谱面 Δt 排在上方（越近越低），底部进度条 + 对/错。仍是「等键」不是按节奏自动下落。
4. 按对：记一次对，指针前进；按错：记一次错，指针不动，错键闪一下。
5. 走完最后一音：停灯，屏显示「完成 对/错」。长按仍只切模式并退出。
