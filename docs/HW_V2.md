## 1. V2 相对 V1：改了什么

| 项 | V1（2026-09-22） | V2（2026-10-09） | 固件影响（回来再改） |
|----|------------------|------------------|----------------------|
| 5V 升压 FP6276 | 有，`BOOST_EN`=IO2 | **删除**，无 `BOOST_EN` / 无升压芯片 | 删升压时序；IO2 另用 |
| `VCC_5V` 负载 | WS2812 / HT6872 / TFT | 负载改挂 **`VSYS`**（电池/USB OR 后） | 上电即可点灯/功放，勿再等 BOOST |
| 矩阵列残影 | 仅靠 CH32 IPD≈40k | **Col1–4 各 10k→GND**（R40/R43/R44/R45） | 可缩短扫键 NOP 延时后实测 |
| INT# | 复查未见板上拉 | **CH32 侧板上拉（R39 10k→3V3）** | 更稳；S3 侧可不重复拉 |
| EC11 A/B 滤波 | 10k↑ + **100n**（TIM2 丢步） | ENC1/ENC2 的 A/B：**仅 10k 上拉，无 100n**；SW 可留 100n | 可恢复硬件正交 / 减软正交复杂度 |
| Reset / Boot | 仅 SW2=IO0，无独立 Reset | **SW4→EN**，**SW2→IO0** | 烧录体验改善 |
| 下载头灌 3V3 | H4 含 3V3，曾反灌 | **H1 = GND / RX / TX / SWIO**，无 3V3 针 | 勿再从 UART 头灌电 |
| 触摸屏 | 仅 8 线 SPI 屏 | **FPC2 18P**：SPI 显示 + **I2C 触摸** + 背光 + `TP-INT` | 新触摸驱动；IO2=`TP-INT` |
| 背光 | TFT_BLK 直驱类 | **VSYS→R42(22Ω)→LED-A**，**U6 AO3400** 受 `TFT_BLK` 开关，LED-K→GND | PWM/`TFT_BLK` 语义变为「开背光 MOSFET」 |
| 麦克风 | 无 | **INMP441**：`INMP_SCK/SD/WS` | 录音/通话类功能预留（现固件未用） |
| PCM5102 XSMT | 硬绑 3V3 | **`XSMT`→CH32 PD0**，**10k 下拉到 GND** | 掉电默认静音；CH32 就绪后拉高 unmute。固件要在 CH32 里管 PD0 |
| 功放输入电阻 | R17/R18 约 10k | **R17/R18=470k，R41=235k** | 增益大变，音量曲线要重标定 |
| DAC 串联 | R15/R16=47Ω | **R15/R16=470Ω** | 输出电平略降，联调时注意 |

## 2. 电源树（V2）

```text
USB Type-C VBUS ──┬── TP4056 ── VBAT ── 电池座
                  │              │
                  │              └── Q2(AO3401) ──┐
                  └── D17(SS34) ─────────────────┼── V_RAW ── Q3+SW1 ── VSYS
                                                 │
VSYS ──┬── MP1605 ── VCC_3V3
       │              （ESP32 / CH32 / DAC / TF / 逻辑 / CW2015 …）
       │
       ├── WS2812 ×15 的 VDD
       ├── HT6872 VDD（喇叭功放）
       └── 屏背光 LED-A（经 R42 + U6）

已删除：FP6276 / `VCC_5V` 升压轨（PDF 上若还有 `VCC_5V` **文字**可忽略，以铜皮/`VSYS` 为准）
```

| 网络 | 含义 |
|------|------|
| `VBUS` | Type-C 5V |
| `VBAT` | 电池 |
| `V_RAW` | USB/电池 OR |
| `VSYS` | 总开关后；**宽电压负载直接吃这路** |
| `VCC_3V3` | 逻辑 3.3V |
| `GND` | 共地 |

**电池大概能到多低：** 单节锂电满电约 4.2V；正常使用多在 **3.5–4.2V**。没有硬 UVLO 时，电量计告警前仍可能被用到约 **3.3V 附近**；再低 MP1605/灯/功放会先不稳，而不是「永远停在安全电压」。建议固件用 CW2015/`BAT_ALRT` 做低电报警并停播，别靠电池自己「不会太低」。

**电源 OR（Q2 反接 + D17）：** Q2 为 **D→VBAT、S→V_RAW、G→VBUS**，R6 100k 把门极拉到 GND。这是常见的 P-MOS 电池 OR：

| 状态 | 行为 |
|------|------|
| 仅电池 | G≈0，体二极管先导通抬起 `V_RAW`，随后 `Vgs` 为负，沟道全开，`V_RAW≈VBAT`（Rdson 压降） |
| 插 USB | G≈VBUS，沟道关断；`V_RAW≈VBUS−V_SS34`（约 4.7V）> `VBAT`（≤4.2V），**体二极管反向截止**，USB 不能经 Q2 倒灌进电池；充电只走 TP4056 |
| SS34 压降 | 约 0.3V，对后级 3V3 DCDC / 功放挂 `VSYS` 足够；为省 BOM 不采用理想二极管是合理取舍 |

**可靠性结论：** 该分立方案在「5V USB + 单节锂电 + TP4056」前提下是可靠、可量产的经典接法；倒灌风险被 Q2 方向本身挡住，不是“凑合能用”。注意点：弱/异常 USB 使 `V_RAW` 跌到接近或低于 `VBAT` 时，电池会经体二极管协助供电（正常 OR 行为）；充电安全仍取决于 TP4056 与电芯保护。

## 3. 矩阵扫键（与现固件极性一致）

现网 CH32 为 **`Matrix_SetInvert(1)`**：

| | 约定 |
|--|------|
| 行 | 空闲低，扫描时该行 **推挽拉高** |
| 列 | **下拉**，按下读 **高** |
| 二极管 | 按下须把「行高」传到「列高」 |
| 板级 | **Col1–4 → 10k → GND**（R40 / R43 / R44 / R45） |

这专门针对 V1 的「内部 IPD 太弱 → 列电容残影 → 假鬼键」。  
**真鬼键**仍靠每键 1N4148；电阻不能替代二极管。

V2 回来后建议：先用现固件（已 invert）冒烟；再逐步缩短 `Matrix_ScanTick` 里的 NOP 延时做对比。

## 6. 屏 + 触摸（FPC2 18P）

连接器：`LAIL-FPC-CX01-18P0.5-W`。

从原理图网标可见（**脚位序号请以 PDF 丝印/模组手册为准**）：

| 功能 | 网络 | S3（核对用） |
|------|------|----------------|
| SPI | `TFT_SCL/SDA/CS/DC/RES` | 见下表 |
| 触摸 I2C | **`I2C1_SDA` / `I2C1_SCL`（与 CH32、CW2015 同总线）** | IO40/41 |
| 触摸中断 | **`TP-INT`** | **IO2**（原 BOOST_EN） |
| 背光阳极 | `LED-A` ← VSYS ← R42(22Ω) ← U6 | `TFT_BLK` 控 AO3400 |
| 背光阴极 | `LED-K` → GND | |
| 逻辑电 | `VCC_3V3` | |

**注意：**

1. 触摸、CH32（0x28）、CW2015 共 I2C——打样前查触摸芯片 7-bit 地址，避免冲突。  
2. `TP-INT` 建议板级上拉（若模组未做）；PDF 上 IO2 侧请确认有上拉。  
3. 固件未到 V2 前：**不要**在现板上假设有触摸。

## 9. 核对结论

### 已按先前建议改对的

- [x] 去掉升压 / `BOOST_EN`  
- [x] 宽电压负载改挂 `VSYS`  
- [x] Col1–4 **10k 下拉**（假鬼键/残影）  
- [x] INT# **板级上拉**  
- [x] ENC A/B **去掉 100n**  
- [x] 独立 Reset（SW4）+ Boot（SW2）  
- [x] 下载头 **不带 3V3**  
- [x] 触摸 FPC + `TP-INT`  
- [x] 背光 MOSFET  

### 已澄清 / 可接受

- [x] `VCC_5V` 残留仅为文字，铜皮按 `VSYS`  
- [x] INT# 上拉在 CH32 侧即可  
- [x] ESP32 脚位以模块局部图为准（§7），麦克风与 TFT 无冲突  
- [x] `XSMT`→PD0 + 下拉，关机爆破方案合理  
- [x] Q2 反接 OR + SS34：可靠；USB→电池倒灌由体二极管方向阻断（见 §2）

### 仍建议留意

1. **触摸与 CH32/电量计同 I2C** — 查触摸地址  
2. **WS2812：VSYS + 3.3V 数据** — 低电/USB 两种电压都测  
3. **功放增益电阻数量级已变** — 回来重标定音量  
4. **H1 含 SWIO** — 和 CH343 接线说明写清楚  
5. **CH32 固件**：上电后适时拉高 PD0（XSMT）；掉电/复位保持高阻让下拉静音
